# Go API client for spectestengine

The versioned integration contract for creating, running, observing, and exporting
SpecTestEngine test assets. The API is project-scoped: the bearer token selects the
company and active project, and clients must not send internal owner identifiers.

Every operation requires a short-lived OAuth 2.0 bearer access token. Interactive
integrations use Authorization Code with PKCE; CI and server-to-server integrations use
Client Credentials. A SpecTestEngine company administrator registers the integration and
approves capabilities through the Integration Builder. The builder offers only capabilities
included in the company's subscription and maps the selection to token scopes. A valid token
cannot enable a capability outside the current subscription. Generate or browse an SDK without
credentials, then provide a token only when calling the API. See the SDK authentication guide
for the complete public procedure.

This alpha contract covers stable request/response workflows plus the bounded asynchronous
lifecycle for WebSocket/WSS, SSE, gRPC Streaming, and MQTT tests. Interactive browser recording,
MCP tools, and AI conversations are documented separately. Browser visual comparison review is
exposed as a bounded preview workflow; live WebRTC transport and worker coordination remain
internal implementation details.
